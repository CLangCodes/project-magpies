# Project Magpies
## Summary
This is a stand alone warehouse application built for a friend to keep track of things they collect from garage sales, antique shops, and fairs. They would like to be able to keep track of where they bought something, how much they spent, what they spent on restoration and other expenses, and how much they sold it for. 

## Infrastructure
Simple; Sqlite, EntityframeworkCore and a wasm application

## Features
- Expense trackking
- Show description and pictures of items in UI
